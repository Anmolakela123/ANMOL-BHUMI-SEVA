# ANMOL BHUMI SEVA — GitHub Pages

यह एक static one-page landing page है।

## GitHub पर लाइव करने का तरीका
1. इस ZIP को extract करें।
2. अंदर की सभी files/folders को GitHub repository के root में upload करें।
3. Settings → Pages → Deploy from branch → `main` → `/ (root)` चुनें।
4. Save करें और कुछ समय बाद GitHub Pages URL खोलें।
