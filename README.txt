# ANMOL BHUMI SEVA — Website

यह GitHub Pages / Netlify / किसी भी static hosting पर चलने वाला responsive website है।

## Publish
पूरे ZIP को extract करके `index.html`, `style.css`, `script.js` और `assets/` folder को hosting के public/root folder में रखें।

## WhatsApp
WhatsApp नंबर पहले से `6207120625` पर configured है।

## WhatsApp Channel
अपना वास्तविक WhatsApp Channel link `script.js` में इस line पर डालें:
`const CHANNEL_URL="https://whatsapp.com/channel/....";`

## Important
यह निजी डिजिटल सहायता वेबसाइट है; इसे सरकारी portal के रूप में प्रस्तुत नहीं किया गया है।
